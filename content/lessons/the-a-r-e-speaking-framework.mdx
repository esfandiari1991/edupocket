  ## A: Answer

  با یک جواب مستقیم به سوال شروع کن. با مقدمه طولانی شروع نکن.

  ```text
  Yes, I think online classes can be effective.
  ```

  ## R: Reason

  یک دلیل روشن بده.

  ```text
  They help students control their schedule and review difficult parts more easily.
  ```

  ## E: Example

  یک مثال مشخص از درس، کار یا زندگی روزانه اضافه کن.

  ```text
  For example, I can replay a grammar explanation before practicing with a teacher.
  ```

  ## تمرین

  به این سوال با A-R-E جواب بده:

  **ترجیح می دهی تنها درس بخوانی یا با دیگران؟**

  جواب خودت را ۴۵ ثانیه ضبط کن. بعد بررسی کن:

  - آیا مستقیم جواب دادم؟
  - آیا یک دلیل آوردم؟
  - آیا یک مثال اضافه کردم؟
  - آیا از جمله های حفظی بی فایده دوری کردم؟

  ## نکته معلم

  اول ساختار را اصلاح کن. بعد گرامر را. جواب روشن با چند خطای کوچک گرامری راحت‌تر از جواب طولانی بدون ساختار بهتر می‌شود.

The A-R-E framework helps learners build clear spoken answers.

![EduPocket A-R-E speaking framework](/images/materials/are-speaking-framework.svg)

## A: Answer

Start with a direct answer to the question. Do not begin with a long introduction.

```text
Yes, I think online classes can be effective.
```

## R: Reason

Give one clear reason.

```text
They help students control their schedule and review difficult parts more easily.
```

## E: Example

Add a specific example from study, work, or daily life.

```text
For example, I can replay a grammar explanation before practicing with a teacher.
```

## Practice task

Answer this question using A-R-E:

**Do you prefer studying alone or with other people?**

Record your answer for 45 seconds. Then check:

- Did I answer directly?
- Did I give one reason?
- Did I include one example?
- Did I avoid memorized filler?

## Teacher note

Correct structure first. Correct grammar second. A clear answer with small grammar errors is easier to improve than a long answer with no structure.
