# EduPocket Original Learning Materials

The assets in this folder were created specifically for EduPocket as original educational visuals.

They are not copied from third-party copyrighted material. Ali Rad / EduPocket may use, edit, publish, and redistribute them freely as part of the EduPocket project.

## Eva Digital Booklet material assets

The SVG files under `eva/` are original EduPocket visual learning aids for the Eva Digital Booklet premium study portal.

They support original reading, writing, listening, pronunciation, exam-mode, and teacher-feedback activities. They do not copy IELTS, TOEFL, ETS, British Council, test-english, or other exam-prep content.

The browser TTS activities use native Web Speech API behavior in the user's browser. No paid audio API or third-party audio file is required for these local learning scripts.
