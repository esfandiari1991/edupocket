# Changelog

All notable EduPocket production changes are tracked here.

## 1.0.2 - 2026-06-02

- Added a package-manager override to keep `postcss` on the patched `8.5.15` release.
- Re-ran production domain checks for `edupocket.org` and `www.edupocket.org`.

## 1.0.1 - 2026-05-31

- Added stronger EduPocket brand motion, hero visual signals, and a refreshed SVG mark.
- Improved collaboration CTA layout so the primary action has clearer hierarchy and secondary contact options sit below it.
- Changed public Instagram button text to `insta` only.
- Added `h1` headings to collection and tag pages for better crawl clarity.
- Expanded page metadata, Twitter cards, and JSON-LD structured data for the site, author, organization, content pages, breadcrumbs, learning resources, and podcast episodes.
- Fixed audio-player state handling so play/pause UI follows real media events.
- Verified with `pnpm lint`, `pnpm check`, `pnpm build`, route checks, and local browser QA.

## 1.0.0 - 2026-05-30

- Launched the first production EduPocket build with bilingual pages, MDX content, English Lab, articles, lessons, podcasts, custom audio player, sitemap, robots, and Vercel deployment support.
